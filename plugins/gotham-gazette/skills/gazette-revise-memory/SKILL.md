# Preserve the newspaper’s memory

Read [packet contract](../gazette-weekly/references/packet-contract.md), the exact published issue, current registry, and existing memory before changes. When Pat requests a narrow edit, change only that content and dependent captions, numbers, or metadata. Preserve unrelated copy, approved artwork, style, archive entries, and past issues.

Correct factual errors visibly when material. Distinguish a real factual correction from the humorous Corrections Desk addressing a bad prediction. Recalculate affected totals, rankings, index, captions, and record claims. Compare ranking movement against the preceding published appropriate board, never a rejected draft. Retain original publication date; record a correction timestamp separately.

After successful publication, maintain a small sanitized record at newsroom/SEASON/week-N.json, respecting any existing equivalent storage. Record issue URL/date, completed fantasy week, normal or special board type and baseline week, rank order, numeric index/components/version, predictions and exact source passage, storylines, jokes used, approved lore changes, art paths/dimensions, source labels, corrections, commit, and deployment verification status. Read the prior record and merge deliberately. Do not replace history with the current draft.

Keep unpublished work distinguished from published state. Never mark the issue published or update the published ranking baseline until production verification succeeds. If a receipt commit changes Git HEAD, record the content deployment commit separately so the audit trail remains truthful. Keep private evidence outside the public repo. Do not persist speculative relationship facts, full manager names, contact details, authenticated links, or unverified NFL statuses.

At the next run, compare prior predictions to verified results and surface only earned callbacks. Themes are per-issue; real league lore and user-approved preferences persist. A claim printed in an old issue is editorial history, not independent proof of a record. Recheck supporting scores before reusing it as fact.
